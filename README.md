# AttendX Test Scripts

Example test scripts for a student attendance application.

## Files

- login_test.py: Tests valid login and empty-password validation.
- attendance_test.py: Tests valid attendance and missing student ID.

## Requirements

- Python 3
- Git

## Run the scripts

python login_test.py
python attendance_test.py

## Note

These are simulated tests. They do not connect to a real
authentication service or attendance database.
